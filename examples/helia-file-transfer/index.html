Helia over QR WebRTC

Two Helia (IPFS) nodes exchange a file over a libp2p connection that was negotiated entirely out-of-band. No relay, no signaling server, no bootstrap list — bitswap simply uses the connection the signed QR handshake produced.

1 Start Helia

Creates a libp2p node with only the QR WebRTC transport, then Helia on top of it.

Peer ID not started

2 Exchange payloads

Browser A: create an offer and copy it. Browser B: paste it and process — an answer appears. Copy that back to browser A and process it there.

Not connected

3 Transfer a file

On one browser add a file to get a CID. On the other, paste that CID and fetch it — the bytes travel over the QR-negotiated WebRTC connection.
